# Rôles BEGPHARMA (CDC §4)

| Acteur | Accès |
|---|---|
| Promoteur / propriétaire | Indicateurs agrégés autorisés ; pas d'accès clinique nominatif implicite |
| Pharmacien titulaire | Responsabilités pharmaceutiques, validation métier, administration officine |
| Pharmacien adjoint / assistant / remplaçant | Actes selon habilitation |
| Responsable qualité | Documents, contrôles, constats, actions |
| Personnel (dispensation, stock, caisse, entretien) | Fonctions nécessaires selon poste + rôle |
| Comptable / expert-comptable | Compta/fiscalité/paie autorisées ; pas d'accès clinique par défaut |
| Administrateur SaaS BEG | Inscriptions, paramètres, exploitation ; pas d'accès auto au contenu sensible |
| Coordinateur / accompagnateur BEG | Missions + accès approuvés par officine, limités temps/périmètre |
| Inspecteur / observateur | Éventuel accès temporaire lecture seule accordé par officine |

Règles : poste RH ≠ qualification ≠ permissions applicatives. Rôles personnalisés ne lèvent pas une restriction de sécurité/habilitation. Plusieurs admins possibles, dernier admin protégé. Multi-rôles par cases à cocher (DEC-04/05).
